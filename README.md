# Spring Villa Guest Lodge & Campsite

Responsive website for Spring Villa Guest Lodge & Campsite in Victoria Falls, Zimbabwe.

The booking pages collect availability enquiries; each request must be confirmed by the lodge. They do not reserve rooms or process payments.

## Publishing

The site is deployed to GitHub Pages from the `main` branch using the workflow in `.github/workflows/pages.yml`.

VS Code can automatically commit and push saved changes when this folder is open. The first time, approve the folder's automatic task when VS Code asks. The watcher groups file events for 1.5 seconds before publishing and reports progress in the dedicated task terminal; stop the `Auto-publish website on save` task to pause it. Changes deploy after each save batch, so review edits before saving and never store credentials, passwords, or private keys in the project.
